# 9.17.0 兼容性记录

## rc.5 首页刷新

刷新「推荐」时，以「刚刚看到这里，点击刷新」上方的普通视频为准。先按当前设置过滤广告和推广，再按视频 ID 去重。少于 10 个时，沿官方推荐接口返回的游标继续取下一页。补回的视频也经过同一套过滤；取得的一批有超过 10 个正常视频时全部保留，奇数个也保留。

当前进程为当前账号记住最近 200 个推荐视频 ID。首批够数就直接显示。网络失败、游标用尽、连续 3 批均无新视频，或补拉时间用尽时，显示已经取得的内容，此时可能少于 10 个。

## 本地广告巡检

9.17.0 的热门页和搜索有独立的广告卡类型。过滤器现在识别热门小卡的广告变体、综合与分类搜索的商业卡，以及动态中的广告类型、转发广告和出现在后续模块中的商品卡。直播购物过滤也处理商品气泡和购物跳转弹窗，「购物精选」可独立控制。新版「我的」菜单按项目过滤「有奖活动」和「开播福利」两个激励入口。

这些规则按广告字段、商品类型或指定菜单项判断。已用广告和普通卡混排、部分开关关闭的数据运行回归测试；实际页面是否投放这些广告由服务端决定。

## 适配范围

本版调整了设置入口、配置读取、Moss gRPC 网络层、OkHttp 网络层、首页 JSON 处理、路由、日志、侧栏、数字格式、评论时间跳转、系统媒体通知、播放器画质和硬件解码定位。9.x 的首页模型改为 KMP FeedItem 后，在 JSON 反序列化前处理推荐流，不再调用旧的 BasicIndexItem 数据接口。

补丁应用成功仅证明入口匹配，不等于所有业务场景已经验证。登录、付费内容、各地区解析服务及所有设备组合不在自动构建检查范围内；本版先以预发布形式提供。

新增回归检查已确认能拒绝旧补丁产生的 8 处错误 Protobuf 调用，避免再次生成安装后崩溃的包。JSON 模型先检查宿主类是否存在，避免新版删除的类型中断其他响应处理。

## 暂不可用

以下补丁在发布配置中明确排除；相应设置禁用，导入旧配置也不会启用它们：

| 补丁 | 暂不可用的增强功能 |
| --- | --- |
| Cache redirect | 外部下载器重定向 |
| Copy enhance | 增强复制评论及视频简介 |
| Custom theme color | 自定义主题配色 |
| Dark switch | 切换深色模式前的额外确认弹窗 |
| Long press playback speed | 自定义长按播放速度 |
| Player gesture detector hook | 禁用长按、双指缩放切换画面比例 |
| Prevent pre download module | 延迟小程序及附加模块预下载 |
| Remember playback speed | 记忆播放速度 |
| Subtitle import and save | 导入、保存字幕 |
| Trial quality | 试用画质辅助 |

客户端自身对应的正常功能不因此被禁用。首页卡片长按屏蔽菜单仍用官方实现；本版不注入旧类型的自定义屏蔽菜单。原上游预构建更新服务已停用，点击模块版本会打开本仓库 Releases。

## 验证

发布脚本检查原包身份和证书、全部选中补丁的应用结果、Protobuf 调用指令是否与方法权限一致、模块 native 库是否存在、APK v1/v2/v3 签名、ZIP 对齐及最终包身份。模块 native 库链接时使用 16 KB 最大页大小；ZIP 对齐不代表已在所有 16 KB 设备上实测。

2026-11-03，本机 Android 11 / API 30 Google APIs 模拟器（x86_64 主机，ARM64 转译）检查结果：

- 完整 APK 安装、同一证书覆盖更新、启动通过。
- 客户端设置中的哔哩漫游 X 入口、模块首页、播放器设置、解析服务器配置框可打开。
- 总开关修改后强制结束客户端并重新启动，状态仍正确保存。
- 暂不支持的字幕导入、长按倍速等设置显示禁用原因，不能误开启。
- 上述流程中未再出现 Java 崩溃，模块日志没有设置或网络 Hook 异常。
- 验证脚本检查 113,156 个公开 Protobuf 方法，未发现残留的非法 direct 调用。
- Python 发布防护测试 5 项通过；GitHub 基础 CI 已成功。

模拟器中的官方原版也出现了 `libndk_translation` 崩溃。播放验收改用 Android 16 ARM64 真机（4 KB 页）。

2026-11-03 的真机测试记录如下。

- 使用固定发布签名覆盖升级成功，冷启动后保留了已有登录状态。
- 修复了 `rc.2` 中 Brotli 解压类继承失败的问题。新增的继承检查会拒绝该旧包，修复后通过了全部 110 个模块类的检查。
- 推荐接口返回正常数据后，旧设置读取逻辑仍访问了 9.17 已移除的 `DeviceSettingProvider`，造成首页加载失败。修复后，冷启动可加载双列推荐卡片、缩略图、标题和时长。
- 普通视频可显示画面和弹幕，AV1 硬件解码持续输出。已验证暂停，以及从约 1 分 15 秒拖动到 4 分 38 秒后继续播放。

### rc.4 默认广告过滤

新安装及从 rc.3 覆盖升级时，首次启动自动启用开屏、推荐流广告/横幅、详情/暂停广告、相关推广、番剧页面广告、推广动态及评论带货过滤，并隐藏商业导航入口。旧版自选的其他过滤条件会保留；之后修改开关不会在下次启动时被重置。首页「推荐」、普通视频和账号会员身份保留。

- 设置位置：「哔哩漫游 X → 首页」管理商城、游戏中心和首页推荐卡；「视频详情页」管理暂停/详情广告；「杂项」管理开屏推广。
- Android 16 真机覆盖 rc.3：同一设备的旧版冷启动曾展示京东广告，更新后冷启动直接进入推荐；底栏「会员购」和顶栏游戏手柄消失，推荐视频正常加载。「我的」页不再显示游戏中心、必火推广、会员购订单和工房。
- 同一普通视频在 rc.3 暂停后出现广告倒计时和半屏商品推广；修复后在 00:42 暂停超过 10 秒，无倒计时或商品广告。继续播放后画面和进度均恢复。
- 「我的」新版大会员推广横幅不再出现；账号会员标识仍在。
- Android 16 真机保留数据覆盖安装 GitHub 发布的 rc.4 后，从手机读取已安装 APK 的 SHA-256，与发布附件一致（`b8b4055526280714d64dc9084af1ef8fe5f6df91f1150d6af67799a458308442`）。同一视频、同一详情页位置对照：先前只适配一套渲染路径的包在合集和话题下方仍显示「视频提及 → 三角洲行动 → 下载」；rc.4 加载完成后，此处直接显示普通相关推荐。游戏卡和下载按钮消失，合集、话题和相关视频保留。
